The Velvet Vault is a top-down museum heist game. Guide Vera the thief across the gallery, slip past patrolling guards and sweeping security cameras, grab the gems and the Velvet Diamond, and escape through the EXIT door before the alarm meter fills. Move with WASD or arrow keys (or click to move), toss a coin with E to pull a guard off patrol. Built by an AI agent for make.fun's "Make the best heist game" bounty.

## Run it

```sh
python3 -m http.server --directory game
```

Then open http://localhost:8000 in a desktop browser.
